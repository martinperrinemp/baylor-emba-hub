Full written Claude setup guide

Prefer guided setup? Go to the short Claude setup page.

About 15 minutes. Do this on a laptop or desktop in Chrome.

By the end you’ll have

  • A private progress Sheet that only you can see
  • A Claude Project called EMBA Planner that already knows the cohort’s rules
  • Claude connected to your Sheet, with a test that proves updates really save

What you need

  • A Claude account. We recommend a paid plan (Pro or higher).
  • A Google account
  • Chrome on a laptop or desktop (or the Claude Desktop app). Claude’s side-by-side Sheet editing works there.

No GitHub account, coding, or earlier AI experience is needed.

Why a paid plan? Weekly planning means long chats. A paid plan gives you much higher usage limits, so Claude is less likely to cut you off mid-semester. The free plan is fine for trying this out, and Projects and the Google connectors are available on it. See claude.ai/pricing for current plans and prices. Live Sheet editing is beta, so neither plan guarantees it.

  1. Make your private progress Sheet

    Open Make a copy of the class tracker. Google will ask you to make a copy. Rename it EMBA Personal Progress, then click Make a copy. In your copy, click Share and confirm access says Restricted.

    Check: You see 55 assignment rows on the Progress tab, with these headings: Assignment · ID · Status · Last Updated. Status and Last Updated start blank, meaning “unconfirmed.” The START HERE tab has a checklist. Use only: Not started (only when confirmed), In progress, Finished not submitted, Submitted, or Blocked. Edit only your copy, never the class template.

  2. Create your Claude Project

    Go to claude.ai/projects and sign in. Click + New project and name it EMBA Planner. On the EMBA Hub, click Copy full text under Step 2, or open the instructions .txt file and copy all its text. It’s plain text, not software. In your project, find Instructions and click Set project instructions. Paste the text and click Save instructions.

    Check: Your EMBA Planner project contains the instructions. Always start EMBA chats inside the project; chats outside it won’t know those rules.

  3. Connect Google

    Open a new chat inside EMBA Planner. Click + in the chat box, hover over Connectors, and turn on Google Drive and Google Sheets. They’re separate connectors: Drive finds and reads files, while Sheets lets Claude edit. Sign in with the same Google account that owns your Sheet and approve permissions.

    Check: Both connectors are enabled for the correct account. Claude can only see files that Google account can see.

  4. Open your Sheet in Claude

    Paste the link to your own copy in the chat and send:
    Open this Google Sheet and read me the column headings on the Progress tab. Do not edit anything.

    Check: Your Sheet opens in a pane beside the chat. If Google requests sign-in there, use the same account as Step 3. Confirm the headings match Step 1; otherwise check the link. If the pane is unavailable, select Open in Google on the file card.

  5. Test that saving works

    Select and copy this exact test prompt:
    In MY private Google Sheet named EMBA Personal Progress, first check whether ID TEST-001 already exists. If it does, stop and ask before reusing it; never create a duplicate or overwrite it without permission. Otherwise, add one fictional row named “Test only” with ID TEST-001, then set Status to “In progress” and Last Updated to the current date and time. Read those two cells back and tell me if the edit really saved. Do not change any real assignments or the publicly shared class template.

    Check: Approve the edit if Claude asks. Look at the Sheet yourself: TEST-001 has Status and Last Updated filled in. Start a new chat in the same project, paste your private Sheet link again, enable the available Google connectors there, and ask, “What is the status of TEST-001?” Claude should read it back from the Sheet. If Claude says “saved” during the semester, check the Sheet.

  6. Clean up and start planning

    Delete the TEST-001 row (or ask Claude to). Then ask your first real question:
    What do I need to complete before our next class weekend? Check the latest EMBA Hub deadlines and readings. Use my private Sheet for confirmed progress, and flag any unverified dates.

    Check: TEST-001 is gone and Claude distinguishes confirmed progress from unverified deadlines. When you submit something, say “I submitted the MGT 5311 Engagement Reflection,” and glance at your Sheet. The Sheet is a snapshot, not a live sync. When new assignments appear on the Hub, ask Claude to add them.

How Claude finds the real dates

The Hub homepage displays deadlines after its JavaScript runs. Some AI page readers see only “Checking…” placeholders. Claude should use the public, no-JavaScript source files instead:

  • Assignment submission deadlines (assignments.json) — submission_due_at; presentation_at where present
  • Readings and preparation (prep.json) — due_or_discuss_date is not necessarily a submission deadline
  • Class schedule (program-calendar.json) — session dates
  • Unresolved alerts (open-alerts.json) — unverified reports requiring official confirmation
  • Publication state (manifest.json) — current knowledge_revision
  • Approved changes (changes.json) — published changes where available

The Hub also exposes an assignments JSON endpoint if the direct GitHub file cannot be opened. If neither source is accessible, Claude must say so rather than invent dates.

Important: Your personal Sheet contains assignment IDs and statuses, not dates. Claude should compare IDs to discover new or unmatched assignments; changes to deadlines require an earlier Hub snapshot or a recorded change. The current Hub contains provisional assignment and preparation dates awaiting review. Canvas and the instructor always take priority.

Optional: add this reliability note to EMBA Planner instructions

When planning my EMBA work, read current public source files directly: https://raw.githubusercontent.com/martinperrinemp/baylor-emba-hub/main/data/assignments.json for due dates and https://raw.githubusercontent.com/martinperrinemp/baylor-emba-hub/main/data/prep.json for readings. Use program-calendar.json for class sessions, and manifest.json plus changes.json for publication and changes. Do not use "Checking..." placeholders on the Hub webpage as evidence. My private EMBA Personal Progress Sheet owns Status and Last Updated, not deadlines. Match IDs exactly, ask before adding or modifying rows, and never invent an update. A changed due date needs an earlier Hub version or an actual change record; do not claim to detect changes by comparing dates with my status-only Sheet. Mark provisional dates as unverified, and defer to Canvas and instructors.

Check: In a new EMBA Planner chat ask: “From the current public assignments.json file, what is the next upcoming submission deadline? Give its title, Central time, and verification status. Do not use the Hub homepage’s loading text.” You should get an actual dated record and source, not a placeholder.

If something goes wrong

ProblemFix
Claude can’t find your SheetPaste the Sheet’s link instead of searching by name.
The Sheet won’t open beside the chatUse Chrome on a laptop or desktop, or click Open in Google on the file card.
Claude says it can’t editCheck that Google Sheets (not just Drive) is on under + → Connectors. If it still fails, update the Sheet by hand. Claude can still plan your week.
“You may need to reconnect your Google Drive account”Go to Customize → Connectors, disconnect the Google connector, and reconnect the next time you use it.
Claude ignores the cohort rulesYou’re probably in a chat outside the project. Open EMBA Planner and start a new chat there.
Claude can’t open the HubAsk it to use web search, and make sure web search is on.

Live Sheet editing is a beta feature and may occasionally misbehave. Your Sheet is always the source of truth. See Claude’s Google Workspace help center.

Privacy and good habits

  • Keep your Sheet Restricted. It holds statuses only, so never add grades, points, personal names, or private Canvas links.
  • The Hub is public. Never paste your filled-in tracker into the public GitHub repository or the correction form.
  • On personal plans (Free, Pro, Max), your chats may be used to improve Claude if you’ve allowed that. Check your privacy settings in Claude.
  • Canvas, syllabi, and your instructors always come first. Before using AI on graded work, confirm the assignment allows it. Unknown does not mean allowed.
