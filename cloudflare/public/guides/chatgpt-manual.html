GET STARTED / CHATGPT

Full written ChatGPT setup guide

Prefer guided setup? Follow the short ChatGPT guide.

Follow these steps in a browser. No GitHub experience required. ChatGPT Projects keep your assistant's instructions and conversations together.

Before you start: Have a Google account and your ChatGPT login. No GitHub account needed. This is easiest on a laptop or desktop browser.

  1. Make your private progress Sheet

    Open Make a copy of the class tracker. In Google's copy window, change the name to EMBA Personal Progress, then click Make a copy. Open your new file and check Share: access should be Restricted. You will see 55 assignment rows with blank Status cells.

  2. Copy the assistant instructions

    On the EMBA Hub, under Step 2, click Or copy full text. That copies the assistant's personality and rules. Prefer a file instead? Download the instruction .txt file, open it, and copy all the text. It is not software to install.

  3. Create your ChatGPT Project

    Open ChatGPT, sign in, and select New project in the left sidebar. Name it EMBA Planner. Open the project, choose the ••• menu → Project settings, and find Instructions. Paste the text from Step 2 and save. Start a new chat inside this project, not on ChatGPT's home screen.

  4. Connect your own Google Drive

    In ChatGPT, open Settings → Plugins (sometimes called Apps). Find Google Drive, choose Connect, and sign in to the Google account that owns your copied Sheet. Review the permissions. If prompted in your Project chat, select Google Drive from the + tools menu.

  5. Make sure it found the right Sheet

    In your EMBA Planner Project chat, paste the link to your own private Sheet and ask: “Read this exact Google Sheet’s Progress tab headings. Do not edit anything.” It should report Assignment, ID, Status, Last Updated. If it finds the class template instead, paste the URL of your own private copy in that private chat.

  6. Test one pretend update

    First ask whether the assistant can write to your private Sheet and explicitly authorize adding one fictional TEST-001 row. Avoid duplicates. Then open your private Sheet in Google to check the new row yourself. Start another chat inside the Project and ask it to read TEST-001 again. If it cannot write or read back, it is not connected for automatic updates. You can still use the planner and update your own Sheet manually.

  7. Start your weekly planning

    Delete TEST-001 from your private Sheet after you approve that deletion and verify it is gone. Then ask the weekly planning question below. Use this same Project for school questions and tell it when you actually submit assignments. Always check Canvas for official deadlines.

Test: did it save?

Copy this into your new assistant (only if you have authorized Google Drive Sheet editing). Check the result in your own spreadsheet.

With my explicit permission and only if TEST-001 does not already exist: In MY private Google Sheet named EMBA Personal Progress, add one fictional row named "Test only" with ID TEST-001, then set Status to "In progress" and Last Updated to the current date and time. Read those two cells back and tell me if the edit really saved. Do not change any real assignments or the publicly shared class template.

You're ready. Try this next:

What do I need to complete before our next class weekend? Check the latest EMBA Hub deadlines and readings. Use my private Sheet for confirmed progress, and flag any unverified dates.

Where ChatGPT finds deadlines

Some page readers cannot render the Hub's live deadline cards. Have ChatGPT read assignments.json, prep.json, manifest.json, and open-alerts.json directly. Ignore superseded_aggregate assignment records. Dates in the public Hub can be provisional; verify Canvas and instructor information. Personal status comes only from your private Sheet.

If you get stuck

Google Drive availability and write permissions depend on your account and plan; paying does not automatically enable spreadsheet edits. Do not share your ChatGPT Project or your completed Sheet with the cohort. If editing fails, you can still use the planner and update your private Sheet yourself. Never trust “saved” without a read-back.
